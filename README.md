# jev-soc-bench

Local benchmark and dashboard comparing TypeSafe Jev with a generative LLM
(`openai/gpt-4o-mini`) on SOC alert triage, both called through OpenRouter.

Work in progress. Results, setup instructions and the method will be added here.

The test suite is kept local and is not published in this repository, so `npm test` on a clone
stops with "No test files found under tests/" instead of reporting a pass.
